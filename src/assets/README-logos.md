Place your company logo at `src/assets/company-logo.png`.

- Supported image types: PNG, JPG, SVG.
- The catalog toolbar will display this image automatically when present.
- If the image is missing or fails to load, the header will show the default text "Catálogo del Supermercado".

Recommended size: 160x36 or similar (the CSS sets height to 36px and preserves aspect ratio).
